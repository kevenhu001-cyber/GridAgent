# Physical features and adaptive policy replay evaluation

Physical retrieval is enabled for the CLI, agent tool and newly started adaptive AC experiments. The previous coarse-only Python API remains the default for compatibility. No migration of the experience SQLite index or previously frozen experiment plans is required. After existing source and candidate replay verification, derive aggregate descriptors from the original AC model and original report: mean branch degree, cycle rank per bus, bridge fraction, median R/X, median reactance in p.u. on a common 100 MVA base, and worst signed voltage/loading/thermal-generator Q margin for the relevant base/outage snapshot category. Topology and impedance descriptors describe the original base topology, not the post-outage graph; parallel branches count separately. Missing, unavailable, invalid or supplementary-rejected measurements are not invented. Signed Q margin is normalized by authorized range width; zero-width ranges are omitted. No raw device settings are transferred or new descriptors persisted to the index.

The score combines coarse structural similarity with an equally weighted electrical descriptor score, reports comparable feature count and omits jointly unavailable descriptors while penalizing one-sided missing values. The fixed replay-study cap and exact rule/snapshot matching remain. This is a hand-designed distance, not calibrated transferability or a probability. New adaptive plans freeze its retrieval weight in the existing hint format; historical plans keep their stored weights.

Run:

    python -m gridagent.ac_policy_benchmark WORKSPACE FIXED_STUDY_ID [MORE_IDS ...] --budget 3

Supply up to twelve distinct committed fixed AC diagnostic studies with complete authorized probe pools and reproduced baseline, ideally source models kept separate from strategy development. Each study is independently replay-verified before evaluation. Both fixed canonical first-fit and adaptive (without historical priors) receive identical pool and budget including baseline, and both stop on the first candidate satisfying all selected-snapshot checks. The offline evaluator reveals an observation only after the policy selects its index. It records selected indices, candidate success, termination, projected solver calls, inconclusive observations, source and report digests and policy replay wall time. Actual solver calls in the benchmark are zero. Repeated identical source report digests are rejected; the caller is responsible for independent model groups and holdout design.

Do not interpret projected calls as measured online speedup, policy replay time as numerical solve time, or these cases as a verified generalization dataset. No surrogate is trained. The policy may perform worse than fixed order. Unit tests include radial/parallel topology, physical margins, missing evidence, and controlled synthetic policy traces. A native workflow test uses a real fixed diagnostic report if the integration environment is available. Subsequent work: prospectively collected independent model families, native wall-time comparisons, calibrated lightweight ranking or surrogate model with abstention.
