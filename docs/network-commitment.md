# Network-constrained commitment and spinning reserve

The unit_commitment family accepts an optional network object, retaining the original single-area contract and hashes when omitted. The connected DC network has 2–20 buses, 1–40 branches, exact equipment-to-bus mappings, per-bus hourly demand matching total demand, a fixed reference bus, an explicit absolute bus-angle bound, and positive branch flow coefficients in MW/rad. For a conventional lossless per-unit model the coefficient is S_base / x_pu, subject to the author's chosen model assumptions. No impedance or voltage conversions are guessed. Each branch has a symmetric MW flow limit and explicit angle-difference limit (at most 0.5 rad).

For each hour, the compiler adds bus angles, signed branch flows and thermal spinning-reserve allocations. It replaces the single-area balance row with bus-level balance; flow is b*(theta_from-theta_to), not unconstrained transport. Storage is placed at its mapped bus. Base-topology connectedness is mandatory; no island dispatch or topology switching. Reserve requirements are hourly system-wide MW values. Every thermal unit declares its maximum eligible MW, including zero. The available allocation cannot exceed declared capability, ramp_up_mw * response_minutes / 60, and online headroom. Only thermal units provide reserve; no reserve cost, activation/recovery model, or post-contingency deliverability. Newly online units may provide reserve under the declared limits; the author must set those limits appropriately.

The existing mathematical-program solver is reused. Independent physical verification reconstructs per-bus balance, reference angle, branch equations, capacity and angle limits, reserve capability and system requirement, in addition to all existing chronology, storage and cost checks. Report includes signed branch flow, loading percent, angles, nodal residuals and reserve allocations/margins. Source and compiled model fingerprints plus version dc-network-commitment-milp-v1 are reserved. The single-area compiler version and report shape are unchanged. The 200-variable and 500-row combined limits include network variables and rows.

This is a base-topology, lossless DC approximation, not AC OPF, security-constrained UC, N-1 verification or proof of reserve deliverability. No reactive power, voltage magnitude, transformer taps, branch resistance, losses, islanding, frequency response or live dispatch. Future work must explicitly model and verify those capabilities. Existing AC IR and PyPSA dispatch are not replaced.

Tests cover analytically checkable two-bus congestion (140 CNY), reverse flow and angle limit, a meshed triangle where DC flow differs from transport, storage at a receiving bus, infeasible reserve/line cases, topology and profile authorization, tampering and durable resume. CI confirmation is required.
