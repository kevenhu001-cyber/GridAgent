# Evidence-guided engineering diagnosis (Phase 6 initial slice)

Use `gridagent --diagnose-study ID`, TUI /diagnose-study ID, or the registered diagnose_engineering_study agent tool. It supports committed mathematical-program-v1 and dc-ac-cross-check-v1 reports, including failed/interrupted studies with a finalized report. It refuses unfinished reports, unknown protocols or changed evidence. It uses the existing deterministic report replay; AC snapshots are rechecked against frozen native requests and artifact digests. No new solver calls, LLM requests, modifications, automatic repair or acceptance relaxation occur in the diagnosis function.

The versioned built-in rule catalog relates exact verifier namespaces to observed symptoms, multiple *untested* physical or numerical hypotheses, and proposed discriminating experiments. It never interprets arbitrary user-defined linear constraint names as physical semantics. It distinguishes solver-reported infeasibility (not certified), missing artifacts (not a physical violation), observed failed checks and optional stationarity diagnostics. Each finding includes check IDs, scenario/run context, observed values where provided, counts and bounded examples, source report fingerprint and rule ID. Linked reference metadata comes from the existing official knowledge summaries where directly applicable. The relations are original heuristics, not expert-reviewed rules or causal probabilities. No root cause is confirmed merely by a failed check. Every suggested experiment needs separate authorization; no experiment is executed by this tool.

A passing report with no failed checks means no failure was observed within the original scope, not system safety. A rejected AC native check does not establish supplementary device outputs that were not verified. Generator-contingency AC validation remains unsupported. Infeasible MILPs may have no primal point; diagnosis gives competing hypotheses and recommended constraint inspections, not an IIS or certificate. General research task and ANDES evidence integration, automatic hypothesis testing, repair authorization, durable diagnostic experiment records and held-out cause-discrimination evaluations are subsequent work.

Tests cover real LP infeasibility and passing cases, interrupted and modified reports, namespace isolation, synthetic contrasting AC evidence and bounded evidence grouping. The tests do not claim diagnostic accuracy on real grids.
