# Corrective DC single-line security commitment

The optional network.security object accepts schema_version 1 and a nonempty list outage_lines of up to eight distinct known branch IDs. All selected branches are removed one at a time, independently for each scheduled hour. The base commitment, storage dispatch, nodal demand and allocated upward reserve are shared. Every outage has its own continuous generation, branch flow and bus angle variables. Failed branch flow is fixed to zero; remaining branches retain normal MW and angle-difference limits. A disconnected post-outage graph uses one deterministic angle reference in each component and exact power balance without shedding in each bus. Island feasibility is a static model condition, not proof of stable island operation.

Online thermal output may change only within existing capacity and minimum output, allocated upward spinning reserve and downward ramp over the same declared reserve response interval. No switching, extra startup, storage recourse or load curtailment is permitted. This is corrective steady-state feasibility after redispatch, not a check of the immediate pre-redispatch transient. The objective remains base-horizon operating cost; contingency operation cost, duration and recovery are not optimized.

The existing MILP solver and independent verifier are reused. The physical verifier recomputes outaged flow, surviving branch equations/limits, component references, nodal balance, capacity and redispatch bounds for each case. The report includes all selected line IDs, post-outage dispatch/flows/angles/residuals, reference buses and whether the selected list covers every line. Source/compiled fingerprints and compiler dc-line-security-commitment-milp-v1 are bound to the same durable reservation. No-security input omits the optional field from canonical data to preserve previous hashes and compiler behavior. The existing 200-variable and 500-row budget includes all recourse variables and equations.

Example: two buses, 6 MW demand at B, cheap A generation 10 CNY/MWh, local B 50 CNY/MWh, 4 MW line. Base-only dispatch costs 140 CNY for one hour. If loss of AB must be feasible, and B can increase its output by at most 2 MW within the response interval, the base schedule must generate at least 4 MW at B, with remaining 2 MW at A. Base cost is then 220 CNY. These are analytic test expectations, not measured benchmarks.

Scope: selected single-line outages only. Full line coverage is reported only if all branch IDs were explicitly selected. Generator outages, transformer-specific models, emergency ratings, voltage/reactive constraints, AC power flow, dynamic stability, protection, frequency response, simultaneous contingencies and real-time control are not implemented. No independent global MILP optimum certificate. Further work: separately authorized AC model mapping and cross-validation, generator outage scenarios, benchmark comparisons.
